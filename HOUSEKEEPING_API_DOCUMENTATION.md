# 🏨 Housekeeping & Hourly Pricing API Documentation

## Overview
This document covers the new housekeeping management system and hourly pricing features added to the Hotel Virat system.

**IMPORTANT:** All existing API endpoints remain unchanged. New features are backward compatible.

---

## 🆕 NEW FEATURES

### 1. Hourly Pricing for Rooms
Rooms can now have hourly pricing options in addition to standard daily rates:
- 3 Hours
- 6 Hours
- 9 Hours
- Standard (Full day/night)

### 2. Housekeeping Management
Complete housekeeping workflow with:
- Task assignment and scheduling
- Real-time status tracking
- Room cleaning status
- Quality inspection
- Performance analytic
